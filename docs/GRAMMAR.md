# Grammar basics

Five original lessons, eight exercises each. Choose Grammar basics in Lesson group.
Suggested order:

| Lesson | Pattern |
| --- | --- |
| Statements | Topic + は + noun + です |
| Negatives | Noun + じゃないです; recognition of ではありません |
| Possession | Owner + の + thing |
| This and that | これ / それ / あれ + は + noun + です |
| Questions | Sentence + か; affirmative and negative replies |

Introductions explain patterns and gloss the words used. Practice includes choosing
whole sentences, interpreting meaning, filling a particle/ending and identifying
the topic/owner. These are multiple-choice exercises, not free typing or draggable
sentence construction. Kana-only sentence spelling keeps kanji recall out of the task.

Conventions:
- は is a topic particle pronounced wa; it is not presented as a translation of “is”.
- です and its negatives are taught in noun statements, not as universal verb rules.
- じゃないです is a conversational polite negative. ではありません is also valid;
  equivalent negatives are not competing choices.
- Ownership is the focus for の, not its only use.
- Demonstrative questions specify speaker/listener distance. Other uses are outside scope.
- Topic omission is explained. An explicit topic is retained for most practice.
- Sentence-final か is taught for these polite questions, not as a requirement for all questions.
- “My friend” translations use the context stated in the lesson.
- This is a first grammar milestone, not a complete N5 curriculum.

Progress uses new grammar-* IDs. Existing question sets, best scores, saved words,
flashcards and the Android bootstrap workaround are unchanged.
Mistake review uses the shared lesson engine and does not replace the original score.
